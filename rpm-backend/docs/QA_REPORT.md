## 직접 확인한 동작

- 외부 전송 동의 없음, 형식 위반, 개인정보 탐지 경로에서 추출기 호출 0회.
- 정상 분석은 최대 1회 호출. 공급자 429/5xx/네트워크 타임아웃에도 SDK 자동 재시도 없음.
- 중복 키·추가 필드·미등록 유형·빈 인용·변형 인용·잘린 출력을 거절.
- 하나라도 틀린 인용이 있으면 정상 근거도 함께 폐기.
- 동일 인용 중복 제거, 반복·겹침 위치와 Unicode/이모지 UTF-16 위치 계산.
- 개인정보 7개 유형, 전각 숫자·포맷 문자·placeholder·값 없는 행동 지시의 경계값 처리.
- 대응 행동 7종과 실제 복수 행동의 모든 유효 조합에서 정렬·중복 제거·우선순위 일치.
- IP/전체 token bucket, 보충 시점, 실패 시 부분 소비 방지, 키 수 상한과 TTL.
- 동시 분석 4개 중 5번째 요청을 503으로 거절. 취소·실제 ASGI 연결 종료·타임아웃 후 슬롯 반환.
- 요청 간 원문 혼합 없음. 호출 후 작업 디렉터리에 사용자 데이터 파일·DB 생성 없음.
- 실제 SDK 요청은 고정 Google API 주소에 단일 user content와 별도 system instruction을 사용하며, URL 실행·도구를 사용하지 않음.
- 실제 서버에서 입력·키·임의 경로/query marker가 응답 오류나 운영 로그에 반사되지 않음.
- 정상·오류 응답 no-store, requestId, CORS, 429/503 Retry-After 규약 확인.

## 실제 Gemini 고정 합성 평가

선택 모델은 `gemini-3.5-flash-lite`다. 팀이 사용할 수 있는 실제 API 환경에서 구조화 JSON 출력을 지원하며 RPM의 행동 요구 추출에 적용할 수 있어 선택했다. 이 평가는 모델 간 성능 비교나 Gemini의 일반 정확도 측정이 아니라, RPM의 고정 합성 샘플에서 행동 유형 추출과 원문 인용 검증을 포함한 전체 흐름이 작동하는지 확인하는 데 목적이 있다.

실제 Gemini 서버 호출은 총 27회 수행했다. 최초 평가 13회에서는 12회가 통과했고 프롬프트 삽입 샘플 1회가 `ACT_LOGIN`을 누락했다. 원인 확인용 단일 호출에서는 `ACT_LINK`, `ACT_LOGIN`과 인용 검증이 통과했다. 이후 메타 지시는 따르지 않되 메시지 안의 실제 행동 요구는 추출하도록 프롬프트를 명확히 했고, 최종 평가 13회가 모두 사전 정의한 행동 유형 및 원문 인용 검증 기준을 통과했다.

| 샘플 | 최종 실행 횟수 | 필수 기대 유형 | 허용 추가 유형 | 실제 추출 유형 | 원문 인용 검증 | 결과 |
|---|---:|---|---|---|---|---|
| 앱 설치 유도 | 3 | `ACT_APP`, `PRESSURE` | `ACT_LINK` | `ACT_APP`, `ACT_LINK`, `PRESSURE` | 통과 | 통과 |
| 로그인 유도 | 3 | `ACT_LOGIN`, `PRESSURE` | `ACT_LINK` | `ACT_LINK`, `ACT_LOGIN`, `PRESSURE` | 통과 | 통과 |
| 계좌정보 입력 유도 | 3 | `ACT_PERSONAL`, `PRESSURE` | `ACT_LINK` | `ACT_LINK`, `ACT_PERSONAL`, `PRESSURE` | 통과 | 통과 |
| 송금 요구 | 1 | `ACT_PAYMENT` | 없음 | `ACT_PAYMENT` | 통과 | 통과 |

## 실행한 검증 명령

```bash
python -m pytest -q --cov=app --cov-report=term-missing
ruff check app tests scripts
ruff format --check app tests scripts
python -m scripts.evaluate_live --allow-external-ai
```

실제 모델 검증은 비식별 가상 fixture에 대해 최종 13회 평가를 수행했다. 최초 평가 13회와 원인 확인용 1회를 포함한 이번 세션의 실제 외부 호출은 총 27회다.

## 구현상 명확히 한 사항

- JSON 깊이 32 제한을 추가해 입력 파서 과부하를 방어한다. 정상 API 계약은 이 깊이를 사용하지 않는다.
- API 계약 제한값은 환경변수만으로 바꿀 수 없게 하여 문서·서버 불일치를 막는다.
- Gemini SDK의 `attempts=1`은 최초 호출 포함 1회다. 실제 SDK의 모의 HTTP 테스트에서 429/5xx에도 요청 1회임을 확인했다.
- 무저장은 앱이 원문·분석·행동을 파일/DB/캐시에 기록하지 않는다는 의미다. 외부 제공자의 처리 정책과 Python 메모리의 물리적 덮어쓰기를 보장하지 않는다.
- 운영 로그 7일 만료는 배포 플랫폼에서 설정해야 한다. Compose 예제는 용량 회전만 제공한다.

## 공개 전 남은 환경 검증

1. 실제 프론트와 origin·UTF-16 하이라이트·응답 상태·브라우저 저장소 동작 확인.
2. 실제 서버의 HTTPS, 프록시 IP 신뢰, body/APM 로그 비활성화, 로그 보존 설정 확인.

위 항목은 미구현된 백엔드 핵심 기능을 뜻하지 않는다. 실제 외부 계정·프론트·배포 환경에서 확인해야 하는 연동 검증이다.
